# HTML do Panorama APS no Tableau

Fonte: `03_LANDING_PAGE/Panorama_APS/index.html`, publicada como `index.html` no repositório `gaiafranklinalexandre-blip/PainelAPS`, com destino **https://apspanorama.onrender.com/**. Este HTML é diferente da landing (`landing_apoiadores_saps.html`) e do Panorama de financiamento gerado na área 02.

Em 26/11/2026, o usuário incluiu a atualização deste HTML no envio autorizado: “falta atualizar o html da página https://apspanorama.onrender.com/”. A versão pública ainda usava o HTML antigo, sem o tema local gov.br. A entrega aplica a versão local com Core 3.7.0 e marca SUS, preservando a URL Tableau, o link de Notas Técnicas e as alturas de 3754/6727 px.

O acesso às Notas Técnicas usa botão secundário, ícone da fonte já incorporada, nome acessível e `rel="noopener"`. O iframe tem título e atributos HTML válidos; sua largura continua em 100% por CSS. `privacidade.css/js` são os mesmos recursos comuns do hub, publicados neste domínio e referenciados por hash. A preferência é isolada por origem; o Analytics próprio só carrega após consentimento. Não alterar os arquivos compartilhados para customizar esta página.

Referências oficiais: [Header](https://www.gov.br/ds/components/header), [Button](https://www.gov.br/ds/components/button), [Estados](https://www.gov.br/ds/fundamentos-visuais/estados) e guia comum do APS 360. As referências detalhadas são da coleta oficial de 21/11/2026; esta entrega não atualiza o Core.

Validação: teclado, foco tracejado, retorno do foco ao fechar preferências, consentimento persistido, oito larguras de 320 a 1920 px, movimento reduzido e ausência de erros JavaScript próprios. A suíte registra os limites relativos ao conteúdo Tableau externo e ao leitor de tela/zoom real. O Nu mantém um apontamento `width:7ch\0` no CSS oficial 3.7.0, já documentado como compatibilidade legada; os dois erros nos atributos do iframe foram corrigidos sem modificar o Core minificado.
